# Use cases (six roles)

- Student: register, view CBTP/internship/project assignments, submit documents, attendance, logbooks, project titles, read feedback and FAQ.
- Academic advisor: review CBTP reports and project titles, monitor groups, record evaluations, view early warnings.
- Internship supervisor: assign internship tasks, review logbooks and attendance, evaluate interns.
- Coordinator: register CBTP sites/activities, assign groups, manage opportunities and placements, generate reports, review matching.
- Host organization: post opportunities, participate in supervision, review intern progress.
- Administrator: accounts, roles, configuration, FAQ corpus, audit log.
