# TrackBridge lives in `trackbridge/`

This branch does **not** change the FarmHelper product.

The FYP app is the folder **`trackbridge/`** (top-level `frontend/` and `backend/` inside that folder).

## Download to your PC

**Zip (no Git):**  
https://github.com/ol-abera/farmhelper-ethiopia/archive/refs/heads/cursor/trackbridge-9fdf.zip

Unzip, then open the `trackbridge` folder.

**Git:**

```bash
git clone -b cursor/trackbridge-9fdf https://github.com/ol-abera/farmhelper-ethiopia.git
cd farmhelper-ethiopia/trackbridge
```

Then follow `trackbridge/README.md` to run it (Node 20, PostgreSQL, demo password `TrackBridge!2026`).
